  • Is SELECT * actually slower?

    Yes — but not because the database reads more data. Roughly 90% of the cost is your client turning columns into objects, and the only case where the projection changes what the engine touches is when it defeats a covering index. That case cost 6.8x here.

    Naming your columns instead of selecting all of them is one of the most repeated rules in code review. Measured on SQLite, the rule is right, but almost every reason given for it is wrong.
